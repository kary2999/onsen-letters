# 温泉乡·漫游 — ONSEN LETTERS

> 穿浴衣去走街

「远方来信 · 日本系列」第 09 号。每天给你一个真实地点 + 一句话。

## 风格
温泉乡 · 模式 `letter`

## 结构
- `index.html` — 今日
- `list.html` — 名录
- `about.html` — 关于
- `assets/style.css` — 样式
- `data/pool.json` — 15 个地点 + 15 句话
- `data/log.json` — 每日打卡记录
- `scripts/daily.py` — 每日定时脚本

## 本地预览
```bash
python3 -m http.server 8088
```

## 数据来源
著名连锁/百年老店/公共景点。营业时间·票务规则·地址以官方为准。
